# 위키 라이브

세 위키 사이트의 공개 편집을 Vite, React, TypeScript로 보여주는 대시보드입니다.

| 출처 | 수집 방법 |
|---|---|
| 위키백과 | Wikimedia EventStreams로 실시간 수신 |
| 위키낱말사전 | 한국어·영어·일본어판 RecentChanges API를 약 20초마다 조회 |
| 위키미디어 공용 | RecentChanges API로 일반 문서·파일·분류 편집을 약 20초마다 조회 |

제목의 대소문자, 공백·밑줄, 유니코드 표기 차이를 정리한 뒤 동일한 제목을 합산합니다. 공용 파일·분류의 접두어와 파일 확장자도 집계할 때 제거합니다. 번역어와 동의어는 각 제목으로 집계합니다. 최다 편집 키워드와 시간대별 키워드에는 사이트별 편집 횟수와 대표 원문 링크가 표시됩니다. 공용 편집은 다국어 데이터로, 언어 필터를 전체로 선택할 때 표시됩니다.

- 실시간 편집 말풍선과 최근 1분, 10분, 1시간의 편집 수 및 최다 편집 문서
- 접속 직전 1시간의 편집을 불러옵니다. 처음 열면 최근 10분이 선택됩니다. 현재 시각을 기준으로 편집마다 선택한 기간이 지나면 집계에서 빠집니다.
- 편집 말풍선은 최대 5개이며, 최근 1분·10분·1시간을 선택하면 각각 5초·10초·20초 동안 표시됩니다. 같은 키워드가 다시 편집되면 해당 말풍선의 표시 시간이 갱신됩니다.
- 전체, 한국어, 영어, 일본어 필터
- 편집 요약, 문서 크기 변화, 문서 링크와 편집 전후 비교 또는 판본·이력 링크
- 최근 24개 시간대의 인기 문서 제목을 IndexedDB에 보관
- 데모 모드. 예시 데이터는 실제 편집 기록에 저장되지 않습니다.

## 로컬 실행

Node.js 22.12 이상인 22 버전 또는 Node.js 24 버전을 사용합니다.

```bash
npm ci
npm run dev
```

빌드 결과를 확인하려면 `npm run build` 후 `npm run preview`를 실행하세요.

## Vercel 배포

1. 기존 GitHub 저장소를 사용한다면 ZIP 안의 프로젝트 **내용물**을 저장소 최상위에 복사합니다. 기존 `.git` 폴더는 그대로 사용하세요.
2. `package.json`, `index.html`, `src/`가 같은 저장소 최상위에 있는지 확인하고 변경 파일을 커밋해 푸시합니다.
3. Vercel에서 **Add New → Project**를 선택하고 해당 GitHub 저장소를 Import합니다. 기존 Vercel 프로젝트가 있다면 그 프로젝트에 연결된 저장소로 푸시합니다.
4. Framework Preset을 **Vite**, Build Command를 `npm run build`, Output Directory를 `dist`로 설정합니다. 새 프로젝트라면 **Deploy**를 선택합니다.

브라우저에서 Wikimedia EventStreams와 공개 RecentChanges API에 직접 접속하므로 배포에 필요한 서버 파일이나 API 키는 없습니다. 시간대별 기록에는 접속 중 새로 발생한 편집을 저장합니다. 접속 전 편집은 최근 수정과 집계에만 표시해 새로고침할 때 기록이 중복 저장되지 않게 합니다. 기록은 브라우저와 사이트 주소별로 분리되며, 같은 주소에서 업데이트하면 기존 IndexedDB 기록을 읽습니다.
